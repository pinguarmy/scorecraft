# 示例乐谱

《初光》是一首 8 小节的原创钢琴小曲。用它可以试试播放、只听左手或右手，也可以练习扫描、对照原稿。

- [MusicXML 源谱](<first-light.musicxml>)：直接导入即可播放，不需要 Audiveris。
- [PNG 谱图](<first-light.png>)和 [PDF 谱页](<first-light.pdf>)：由同一份源谱生成，可用来试用本机识谱。
- [反复练习](<repeat-study.musicxml>)：一份用来练习反复记号的原创短谱。
